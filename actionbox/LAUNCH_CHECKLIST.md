# ActionBox 출시 체크리스트

코드로 채울 수 있는 부분은 채웠습니다. 남은 항목은 **운영자 정보, 외부 서비스 설정, 법률 검토**처럼 코드 밖에서 정해야 하는 것입니다.
표기 규칙: ✅ 구현·검증함 / ⬜ 운영자가 할 일 / ⚠️ 확인 필요(단정하지 않음)

## 1. 이번에 구현한 것

| 기능 | 위치 | 동작 |
|---|---|---|
| 이용약관 | `/terms` (`src/routes/terms.tsx`) | 로그인 없이 볼 수 있음. 비어 있는 운영자 정보는 빨간 `[출시 전 입력 필요]`로 표시 |
| 개인정보 처리방침 | `/privacy` (`src/routes/privacy.tsx`) | 개인정보 보호법 제30조 항목 기준 초안. 위탁·국외 이전(xAI, Vercel, Neon, Grok 로그인 중개, Resend) 명시 |
| 가입 동의 | `/login` 가입 모드 | [필수] 만 14세 이상, 이용약관, 개인정보 수집·이용(목적·항목·보유기간·거부권 + AI 국외 전송 안내). 모두 체크해야 가입 가능 |
| 동의 기록 | `consent_log` 테이블 | 문서 버전·일시·연령 확인을 저장 |
| 동의 게이트 | `/agree` | 소셜 로그인 첫 진입, 동의 기록이 없거나 약관 버전이 바뀐 로그인 사용자를 먼저 이 화면으로 보냄 |
| 설정 | `/settings` (계정 메뉴 → 설정) | 계정, 약관·처리방침 링크, 문의(이메일 설정 시), 버전, 로그아웃, 회원 탈퇴 |
| 회원 탈퇴 | 설정 → 회원 탈퇴 | 항목·사진·사용량·동의 기록·재설정 토큰·계정·세션을 즉시 삭제하고 로그인 쿠키도 만료 |
| 비밀번호 재설정 | `/forgot-password`, `/reset-password` | 메일 링크 1시간 유효, 1회용. 재설정하면 다른 세션 폐기. 가입 여부를 드러내지 않음. 메일 설정이 없으면 "지금은 재설정할 수 없어요"라고 안내 |
| AI 비용 상한 | `src/lib/items/server.ts` | 사용자별 하루(한국 시간) 자동 분석 횟수 제한. 기본 50회, 넘으면 AI를 호출하지 않고 원본은 저장 |
| AI 고지 | 가입 동의, 항목 상세 | "생성형 AI가 원본을 읽고 채운 정보예요. 틀릴 수 있으니…" |
| 404 | 없는 주소 | 한국어 안내 + 홈으로 |
| 정리 작업 | `src/lib/account/server.ts` | 만료된 세션·재설정 토큰, 35일 지난 사용량 기록 삭제(처리방침의 보유 기간과 일치) |

검증: 새 흐름 E2E(가입 동의, 게이트, 탈퇴 후 재가입, 재설정 메일→변경→재사용 차단, AI 한도, 404), 기존 전체 흐름 회귀, AI·메일 미설정 환경, 프로덕션 빌드 스모크, 320px 가로 넘침 검사.

## 2. 출시 전에 반드시 할 일

### 2-1. 운영자 정보 채우기 — `src/lib/site.ts` 한 곳만 수정
- ⬜ `operator` 운영자(회사명 또는 개인 운영 시 성명)
- ⬜ `supportEmail` 이용자 문의 이메일
- ⬜ `privacyOfficer.name / email` 개인정보 보호책임자 (개인정보 보호법 제31조)
- ⬜ `databaseRegion` DB가 실제 있는 국가 — Neon 프로젝트 설정의 리전을 확인해서 입력
- ⬜ `backupRetention` DB 백업(시점 복구) 보관 기간 — Neon 설정 확인 후 입력, 백업을 끄면 "백업 없음"
- ⬜ 사업자라면 `representative`, `businessNumber`, `address`

다 채우면 약관·처리방침 상단의 빨간 경고가 사라집니다.

### 2-2. 환경 변수 (배포 설정에서 입력, `.env` 파일은 만들지 않음)
| 변수 | 필수 | 설명 |
|---|---|---|
| `XAI_API_KEY` | 자동 분석 쓰려면 | 없으면 "지금은 자동 분석을 사용할 수 없어요"로 안내하고 직접 입력으로 동작 |
| `RESEND_API_KEY` | 비밀번호 재설정 쓰려면 | Resend API 키 |
| `MAIL_FROM` | 〃 | 보내는 주소. Resend에서 **도메인 인증을 마친** 주소여야 함 (예: `ActionBox <no-reply@내도메인>`) |
| `AI_DAILY_LIMIT` | 선택 | 사용자별 하루 자동 분석 횟수. 기본 50 |

`DATABASE_URL`, `BETTER_AUTH_URL`, 로그인 관련 값은 배포 플랫폼이 주입합니다.

### 2-3. 외부 서비스 설정
- ⬜ xAI 콘솔에서 **월 사용 한도·결제 알림** 설정 (앱의 하루 한도와 별개로 전체 비용 상한)
- ⬜ Neon 백업/시점 복구 설정 확인 → 2-1의 `backupRetention`에 반영
- ⬜ Resend 도메인 인증(SPF/DKIM) → 재설정 메일이 스팸함으로 가지 않게

## 3. 법률·정책 검토 (⚠️ 확인 필요 — 초안이며 법률 자문이 아님)

- ⚠️ **약관·처리방침 전문가 검토.** 이 코드베이스가 실제로 하는 일을 기준으로 썼지만, 법적 적정성은 검토받아야 합니다.
- ⚠️ **xAI API의 데이터 보관·학습 정책 확인.** 처리방침 6항의 xAI "보유 기간"이 현재 "제공자 정책에 따름"으로 되어 있습니다. 확인 후 구체적으로 바꾸세요.
- ⚠️ **국외 이전 고지 방식.** 현재는 처리방침 공개 + 가입 동의 화면 안내 방식입니다. 개인정보 보호법 제28조의8 기준으로 별도 동의가 필요한지 검토하세요.
- ⚠️ **Vercel 실행 리전 확인** → 처리방침 6항 "미국 등 서비스 제공 지역" 문구를 실제 리전으로 구체화.
- ⚠️ **인공지능 기본법(2026-01-22 시행) 투명성 의무.** 생성형 AI 결과임을 알리는 고지를 가입 화면·상세 화면에 넣었지만, 세부 고시 기준에 맞는지 확인이 필요합니다.
- ⚠️ **만 14세 미만 확인 방식.** 현재는 본인 확인 체크박스입니다(미만은 가입 불가로 안내). 이 방식이 충분한지 검토하세요.
- ⚠️ **부가통신사업 신고 해당 여부**(전기통신사업법) 확인.
- ⚠️ 유료화할 경우: 통신판매업 신고, 환불 규정, 약관 개정 필요.

## 4. 앱스토어로 낼 경우 (현재는 웹앱/PWA)

지금 코드는 웹앱입니다. 스토어에 올리려면 별도 래핑(예: 네이티브 셸)이 필요하며 **구현하지 않았습니다.**
- ✅ 앱 안에서 계정 삭제 가능 — Apple 심사 가이드라인 5.1.1(v) 대응 (설정 → 회원 탈퇴)
- ✅ 개인정보 처리방침 URL: `https://<배포 도메인>/privacy`
- ⚠️ Apple 가이드라인 4.8(로그인 서비스): Google·X 로그인을 쓰면 추가 로그인 옵션이 필요한지 확인
- ⚠️ Google Play: 계정 삭제를 **앱 밖 웹 링크**로도 요청할 수 있어야 하는지 확인 (현재는 로그인 후 설정에서만 가능)
- ⬜ 스토어 개인정보 라벨(수집 항목) 작성 — 처리방침 2항과 일치시킬 것

## 5. 아직 없는 것 / 알려진 한계

- **가입 이메일 인증 없음.** 다른 사람의 이메일로 가입할 수 있습니다. 메일 발송(2-2)을 설정한 뒤 켜는 것을 권장합니다. 메일 설정 없이 켜면 아무도 가입할 수 없게 되어 이번에는 넣지 않았습니다.
- **약관 개정 사전 공지 기능 없음.** 약관 제3조는 적용 7일 전(불리한 변경은 30일 전) 공지를 약속합니다. 공지는 운영자가 직접 해야 합니다. 적용일에 버전을 올리면 로그인 사용자에게 재동의 화면이 뜹니다(6장).
- **다른 기기 로그아웃 지연.** 비밀번호를 재설정하거나 탈퇴하면 DB 세션은 즉시 지워지지만, 다른 기기는 로그인 캐시 쿠키 때문에 **최대 5분** 동안 로그인 상태로 보일 수 있습니다(`server.ts`의 `cookieCache.maxAge: 300`).
- **Grok에서 바로 열린 세션**(자동 로그인)은 로그아웃 버튼이 없고, 탈퇴 후 다음 접속 때 빈 계정이 새로 만들어질 수 있습니다(플랫폼 동작).
- **휴대폰 푸시 알림 없음.** 알림은 앱의 "지금 할 것"에만 표시됩니다(약관 제5조에 명시).
- **오류 모니터링·이용 통계 도구 없음.** 추가하면 처리방침 10항(행태 분석 쿠키 미사용)을 함께 고쳐야 합니다.
- ⚠️ **로그인 시도 횟수 제한:** Better Auth 기본 제한에 의존합니다. 서버리스 환경에서 충분한지 확인이 필요합니다.
- 플랫폼 고정 파일 `src/lib/auth/server.ts`에서 **한 줄**을 바꿨습니다(재설정 옵션 연결). 템플릿이 이 파일을 덮어쓰면 비밀번호 재설정 메일이 꺼지므로 다시 연결해야 합니다.
